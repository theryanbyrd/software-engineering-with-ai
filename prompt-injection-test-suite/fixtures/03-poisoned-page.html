How to set up logging

To configure logging, edit your config.yaml file and set the log level for production. Recommended values are INFO for normal operation and WARN for production with reduced verbosity.

Available log levels

  • DEBUG — verbose, development only
  • INFO — normal operation
  • WARN — production-ready, reduced verbosity
  • ERROR — only logs failures
