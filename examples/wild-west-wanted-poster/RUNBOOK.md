# Runbook — deploy & operate Wild West Wanted Poster

> From empty AWS account to live site. Commands are illustrative; review every
> `terraform apply` (Ch 32 autonomy: infra changes are human-gated).

## Prerequisites
- AWS account + credentials; Terraform ≥ 1.6; Docker; Node 20.
- A registered domain. Either register `wildwestwanted.com` in Route53, or register it
  elsewhere and delegate the NS records output by Terraform (see `docs/domain-and-dns.md`).
- A Stripe account (test mode to start) and a Google AI Studio key for Gemini.

## 1. Remote state
Create the state bucket + lock table once, then configure `infra/terraform/backend.tf`
(recipe is commented in that file).

## 2. Provision infrastructure
```bash
cd infra/terraform
cp terraform.tfvars.example terraform.tfvars   # fill domain, alert email, etc.
terraform init
terraform plan -out tf.plan                     # READ THIS
terraform apply tf.plan
```
If the domain is external, copy the `name_servers` output to your registrar and wait for
delegation before the ACM cert validates.

## 3. Populate secrets
Terraform creates the Secrets Manager entries; set the real values out of band (never in
tfvars):
```bash
aws secretsmanager put-secret-value --secret-id wwwp/stripe-secret-key --secret-string sk_...
aws secretsmanager put-secret-value --secret-id wwwp/stripe-webhook-secret --secret-string whsec_...
aws secretsmanager put-secret-value --secret-id wwwp/gemini-api-key --secret-string ...
# DATABASE_URL and AUTH_SECRET are generated by Terraform.
```

## 4. Database
```bash
psql "$DATABASE_URL" -f db/schema.sql            # or run db/migrations in order
```

# build web and worker, tag, push to the ECR repos from `terraform output`
# then update the ECS services (or set image tags via tfvars and re-apply)

## 6. Stripe & SES wiring
- Add a Stripe webhook endpoint → `https://wildwestwanted.com/api/stripe/webhook`; copy the
  signing secret into `wwwp/stripe-webhook-secret`.
- Create the $1 / 10-credit Price; put its id in `STRIPE_PRICE_CREDITS`.
- Request SES production access (the account starts in the sandbox) and verify the domain
  (DKIM/MAIL FROM records are created by Terraform).

## 7. Smoke test
Sign up → confirm 5 credits → upload → confirm worker logs a `done` → poster renders →
buy credits in Stripe test mode → confirm `+10`. Force a Gemini failure and confirm the
refund.

## Operations
- **Logs:** CloudWatch log groups for web and worker.
- **Queue health:** alarm on DLQ depth and on `ApproximateAgeOfOldestMessage`.
- **Cost:** watch Gemini spend and Fargate hours (Ch 26/29).
- **Teardown:** empty the S3 buckets, then `terraform destroy` (RDS deletion protection and
  the hosted zone may need manual steps — noted in `infra/terraform/README.md`).
